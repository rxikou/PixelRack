# Design System

The visual language, retro palette, and typography used across PixelRack.

See [PixelRack_Documentation/style.md](../PixelRack_Documentation/style.md) for the complete token definitions and [PixelRack_Documentation/design_system.docx](../PixelRack_Documentation/design_system.docx) for component swatch documentation.

## Typography
- **Headings & Badges:** Jersey 10 (Google Fonts)
- **Body & Captions:** Roboto Mono (Google Fonts)

## UI Palette & Chrome
- **Background Deep:** `#0b1020`
- **Panel Surface:** `#161f38`
- **Panel Border:** `#05070d` (chunky 2px to 4px borders)
- **Primary Accent:** `#ffd214` (Arcade Yellow)
- **Secondary Accent:** `#38bdf8` (Retro Blue)
- **Wood Shelf:** `#8b4513` and dark brown grain shadows
